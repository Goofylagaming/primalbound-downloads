# Primalbound World — Windows playtest

Official desktop playtest downloads. The first verified Windows release is being prepared.

## Download

Once the first release is published:

- [Download for Windows](https://github.com/Goofylagaming/primalbound-downloads/releases/latest/download/PrimalboundWorld-Windows.zip)
- [Latest release and checksum](https://github.com/Goofylagaming/primalbound-downloads/releases/latest)

## Play

1. Download the Windows ZIP.
2. Extract the entire ZIP to a folder.
3. Run `PrimalboundWorld.exe`.
4. Read `PLAYTEST.txt` for controls, save migration and known limits.

No Godot installation or GitHub account is needed to download a published build. This is a development playtest.

## Updates

The download link stays the same. Only builds that pass both source and packaged Windows verification are eligible for publication. If a new build fails, the previous verified download stays available. Download and extract the new version when you want to update; installed copies do not update themselves.

## Feedback

[Report a problem](https://github.com/Goofylagaming/primalbound-downloads/issues/new) and include your milestone/build from `BUILD_COMMIT.txt`, Windows version, and steps to reproduce it. Do not include personal information in public reports.

This repository distributes game builds and instructions. The development source repository remains private.
